# Reglas de Git y Control de Versiones

- **No realizar commits automáticos:** No ejecutes comandos `git commit` ni `git push` automáticamente ni por iniciativa propia.
- **Control del usuario:** Deja las modificaciones, creaciones o eliminaciones de archivos en el árbol de trabajo (working directory / stage) para que el desarrollador las revise y decida cuándo y con qué mensaje realizar los commits.
- **Excepción:** Solo ejecuta `git commit` si el usuario lo solicita explícitamente en su mensaje.
